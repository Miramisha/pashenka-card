# Паша, это всё тебе ♡

Личная открытка на русском языке: письмо, поцелуй на весь экран, пожелания, три пасхалки и игровой сюрприз в духе стана Breach из VALORANT. Неофициальный фанатский эффект, без игровых ресурсов Riot Games.

## Запуск

Нужен Node.js >= 22.13 и pnpm.

```sh
pnpm install
pnpm dev
```

## Проверка

```sh
pnpm exec tsc --noEmit
pnpm build
```

Тексты и поведение находятся в `app/page.tsx`, оформление — в `app/globals.css`, заголовок — в `app/layout.tsx`.

Анимации учитывают системную настройку уменьшения движения. Фоновое пианино запускается после первого взаимодействия. Кнопка звука выключает музыку и эффекты. На время флешки и стана музыка приглушается. Данные посетителей не собираются.
