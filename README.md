# Пашенька, это всё тебе ♡

Романтическая интерактивная открытка ко дню рождения: тёплое письмо, маленькие сюрпризы и праздник после нахождения всех пасхалок.

**[Открыть сайт](https://pashenka-love.karina-kuslina-04.workers.dev/)**

## Что внутри

- Письмо и поцелуй на весь экран.
- Конверт с пятью открытками-пожеланиями.
- Мультяшная лисичка, которая дарит сердечко.
- Сюрприз с флешкой и станом Breach из VALORANT.
- Человек-паук с воздушными шариками, которые можно лопать.
- Розовая шкала пяти найденных секретов.
- Финальное поздравление с тортом, свечами, хлопушками и конфетти.
- Фоновая музыка и звуковые эффекты с кнопкой выключения звука.

Музыка включается после взаимодействия со страницей. Анимации учитывают системную настройку уменьшения движения. Свечи задуваются кнопкой — микрофон не нужен.

## Технологии

React 19, TypeScript, vinext, Vite, Tailwind CSS и Base UI. Сайт опубликован на Cloudflare Workers со статическими ресурсами.

## Локальный запуск

Нужны Node.js версии 22.13 или новее и pnpm.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Адрес локального сервера появится в терминале.

## Проверка и сборка

```sh
pnpm exec tsc --noEmit
pnpm build
```

## Публикация на Cloudflare

После авторизации в своём аккаунте Cloudflare:

```sh
pnpm exec wrangler login
pnpm build
pnpm exec wrangler deploy --config dist/server/wrangler.json --name pashenka-love
```

Адрес опубликованного сайта выводится после завершения команды. Домен Workers зависит от аккаунта Cloudflare. Файл `.openai/hosting.json` относится к первоначальной публикации через Sites.

## Основные файлы

- `app/page.tsx` — главная страница и учёт пасхалок.
- `app/globals.css` — оформление и анимации.
- `app/fox-surprise.tsx` — лисичка с сердечком.
- `app/spider-surprise.tsx` — Человек-паук и шарики.
- `app/birthday-finale.tsx` — праздничный финал.
- `app/use-card-audio.ts` — управление музыкой и игровыми звуками.
- `public/` — изображения и аудио.
